PIZZARIA D'CASA — CONTADOR SEQUENCIAL DE PEDIDOS

O que foi adicionado:
- Cada novo pedido recebe um número sequencial (#1, #2, #3...).
- O número aparece no painel administrativo, na mensagem enviada para o WhatsApp e nas mensagens de atualização de status.
- O botão “Resetar numeração” no painel faz com que o próximo pedido seja #1. Pedidos antigos mantêm o número que já tinham.
- A contagem é centralizada no Supabase para evitar números duplicados se dois clientes pedirem ao mesmo tempo.

PASSO OBRIGATÓRIO ANTES DE TESTAR
1. Abra o painel do Supabase do projeto usado pela pizzaria.
2. Entre em SQL Editor > New query.
3. Abra o arquivo SQL-CONTADOR-PEDIDOS.sql deste pacote, copie todo o conteúdo, cole no SQL Editor e execute uma vez.
4. Confira se a execução terminou sem erro.
5. Só então publique os arquivos do pacote na hospedagem.

TESTE RECOMENDADO
1. Faça um pedido de teste e confirme que aparece como Pedido #1 no admin e no WhatsApp.
2. Faça outro pedido e confirme que aparece como Pedido #2.
3. No admin, clique em “Resetar numeração” e confirme.
4. Faça outro pedido e confirme que ele recebe #1.

IMPORTANTE
- O reset não apaga pedidos nem altera os números já atribuídos aos pedidos antigos.
- A função de reset exige login autenticado no Supabase.
- Faça backup dos arquivos atuais da hospedagem antes de substituir qualquer arquivo.
- A validação feita aqui é sintática; o SQL e o fluxo precisam ser testados no projeto Supabase real antes de usar com clientes.
